# Лабораторная работа №3
## Порождающие паттерны проектирования

**Тема проекта:** система бронирования отеля.

**Цель работы:** изучить четыре порождающих паттерна проектирования и реализовать их на языке Python.

### 1. Singleton (Одиночка)
Реализован в файле `singleton/hotel_settings.py`.

Класс `HotelSettings` хранит общие настройки отеля: название, время заселения и выселения. При повторном создании возвращается тот же объект.

### 2. Factory Method (Фабричный метод)
Реализован в папке `factory_method`.

Созданы два типа номеров:
- `StandardRoom` - стандартный номер.
- `LuxuryRoom` - люкс.

Классы `StandardRoomCreator` и `LuxuryRoomCreator` создают соответствующие номера через метод `create_room()`.

### 3. Abstract Factory (Абстрактная фабрика)
Реализован в папке `abstract_factory`.

Созданы две фабрики:
- `EconomyFactory` - стандартный номер и обычное обслуживание.
- `PremiumFactory` - люкс и VIP-обслуживание.

Каждая фабрика создаёт набор связанных объектов.

### 4. Builder (Строитель)
Реализован в папке `builder`.

Класс `BookingBuilder` позволяет постепенно создать бронирование: указать гостя, номер, количество ночей и дополнительные услуги - завтрак и трансфер.

### Запуск программы

Из корневой папки репозитория выполнить:

```bash
py lab3/main.py
```

### Вывод

В ходе лабораторной работы были реализованы четыре порождающих паттерна проектирования на примере системы бронирования отеля. Каждый паттерн показывает отдельный способ организации создания объектов.
