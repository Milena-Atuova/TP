# Лабораторная работа №2 — Основы ООП

## Цель работы

Изучить основные принципы объектно-ориентированного программирования и реализовать иерархию классов на Python.

## Задание

Разработать систему классов для компьютерной игры в жанре пошаговой стратегии.

Реализовать следующие классы:

- **GameObject** — базовый класс игровых объектов. Содержит ID, имя и координаты.
- **Unit** — класс юнитов, имеющих здоровье и способных получать урон.
- **Archer** — лучник, который может перемещаться и атаковать.
- **Building** — класс построек.
- **Fort** — крепость, способная атаковать.
- **MobileHouse** — дом на колёсах, способный перемещаться.

Реализовать интерфейсы:

- **Attacker** — возможность атаковать.
- **Moveable** — возможность перемещаться.

## Принципы ООП

1. **Наследование** — классы получают свойства и методы родительских классов.
2. **Инкапсуляция** — данные объекта объединяются с методами для работы с ними, доступ к состоянию контролируется.
3. **Полиморфизм** — разные объекты реализуют общее поведение по-разному.
