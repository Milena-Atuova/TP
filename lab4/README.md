
# Лабораторная работа №4
## Поведенческие паттерны проектирования

**Тема:** Система управления отелем

**Язык программирования:** Python

### Цель работы

Изучить поведенческие паттерны Strategy, Chain of Responsibility и Iterator и реализовать их на примере отеля.

### 1. Strategy (Стратегия)

В этом паттерне я сделала расчет стоимости проживания в отеле.

Есть три тарифа:
- `RegularTariff` - обычная цена без скидки.
- `LoyalGuestTariff` - скидка 10% для постоянных гостей.
- `WeekendTariff` - тариф с наценкой 20%.

Класс `PriceCalculator` отвечает за расчет стоимости.

С помощью метода `set_tariff()` можно менять тариф, не изменяя сам класс.

### 2. Chain of Responsibility (Цепочка обязанностей)

Здесь я реализовала проверку бронирования перед его подтверждением.

Проверки идут по очереди:
1. `GuestCheck` - проверяет имя гостя.
2. `NightsCheck` - проверяет количество ночей.
3. `RoomsCheck` - проверяет наличие свободных номеров.

Если одна из проверок не пройдена, программа выводит ошибку.

Если все проверки прошли успешно, бронирование подтверждается.

### 3. Iterator (Итератор)

В этом паттерне я сделала перебор номеров отеля.

Класс `HotelRooms` хранит номера отеля.

Класс `RoomIterator` позволяет просматривать их по очереди.

Для перебора используются методы `__iter__()` и `__next__()`.

Когда номера заканчиваются, вызывается `StopIteration`.

### Запуск программы

Открыть терминал в корневой папке репозитория.

Ввести команду:

`py lab4/main.py`
